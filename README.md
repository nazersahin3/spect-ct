# SPECT/CT Liver Analysis - Development Repository

## Overview

This repository contains the working files, experimental scripts and earlier implementations developed throughout my 2026 Physics Honours research project investigating regional liver function following stereotactic body radiation therapy (SBRT).

It serves as a record of the computational development process, including testing, troubleshooting and refinement of the image-processing and quantitative analysis workflow.

## Repository contents

The repository contains various scripts relating to:

- Medical image conversion and preprocessing.
- Anatomical segmentation and visualisation.
- Rigid and deformable image registration.
- Registration quality assurance and troubleshooting.
- SPECT-derived functional quantification.
- Regional and voxel-wise radiation dose–response analysis.
- Experimental approaches and intermediate processing outputs.

## Important notes

**This is a development archive, not the final analysis pipeline.**

Some files represent preliminary approaches, intermediate versions, testing scripts or methods that were subsequently revised or discontinued. Scripts may contain outdated settings, local file paths or incomplete implementations and should not be assumed to reproduce the final thesis results.

The curated scripts associated with the final methodology are maintained in a separate repository.
